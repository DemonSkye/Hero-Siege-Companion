**Hero Siege Companion v0.2.0**

Npcap is still required for capture: https://npcap.com/#download
Install with WinPcap API-compatible mode enabled.

**What's new**
- Past Runs search across tags, drops, resources, characters, and run stats.
- Per-run tags for organizing saved runs.
- Loot alert audio imports for local sound files and zip soundpacks.
- Imported sounds can be assigned to rarity groups or exact watched items.
- Dark, Cyberpunk, and Light themes with separate full-app and compact choices.
- Accent colors and theme import/export for shareable app chrome customization.
- Custom dashboard tiles for full and compact views.
- Settings now has a What's New panel with a one-time update prompt.

**Polish / fixes**
- Cyberpunk theme got a warmer glow and smoother panel animation.
- Live Session now matches the page background style used by Item Filter and Past Runs.
- Compact mode now respects its own theme while active.
